# 4. Screens, alarms, and the archive

Status: outlined

## Job

Show the three operator-facing services that sit on the PVs: a screen, an alarm, and a history.

## Covers

- Screens as a view, not a second control system. Phoebus is the current usual client; older display managers are the installed base the reader will still meet.
- Alarms as a filtered stream. An alarm tree is configured from names and tags, which is why chapter 3 exists.
- The archive as the memory of a shift. What gets archived is a choice. Channel Finder is one way sites make that choice.
- How an on-call engineer uses the three together: see the screen, check whether it alarmed, check whether the value had been drifting.

## Stays out

- Screen-editor tutorials.
- Archive appliance internals.

## Draws on

- Phoebus and the alarm and archive services documented with it.
- PV Info as the public example of a directory client: <https://github.com/ChannelFinder/pvinfo>
